# Актуализация инструкции существующего продукта

21 ноября 2026. База — `134a32b` (main после первой волны и контрактов второй). Ветка — `codex/existing-product-alignment`. Изменены корневой README и пустой `scripts/compose-services.env`; прикладной код, сервисы, миграции и контракты не менялись.

## Исправленная проблема

Инструкция legacy предлагает корневой `.env` с `DATABASE_URL` и `POSTGRES_PORT=5432`. Запуск отдельного Compose из того же каталога может передать эти значения в Hiring/Workforce: контейнер попытается подключиться к legacy URL через собственный localhost, а порт БД совпадёт с 5432. README теперь явно разделяет процессы, окружение, миграции, порты и входы и задаёт отдельный env-файл для стандартных сервисных значений. Переменные shell остаются приоритетными, поэтому описана их очистка в отдельном терминале.

Дополнительно перечислены существующие функции, ручной переход в Hiring этапа 1, отсутствие единого gateway/общей авторизации, краткая проверка доступности и фактическое удаление тестовой схемы при полном DB-наборе.

Первый env — копия опубликованного `.env.example`, второй — пустой. Настоящие секреты и локальный `.env` в вывод не попадали.
