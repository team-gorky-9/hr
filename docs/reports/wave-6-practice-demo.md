## Повторить

Из `services/students`, PowerShell:

```powershell
uv sync --python 3.13 --dev
$env:WAVE6_REPORT_DIR = '../../docs/reports'
uv run pytest tests/test_wave6_demo.py -q -s
```

Проверка создаёт временную SQLite с миграцией `0001`, запускает настоящий uvicorn,
выполняет HTTP-запросы, останавливает процесс и перечитывает ту же БД вторым процессом.
При повторе UUID и время будут новыми. Переменная отчёта необязательна; с ней
перезаписывается только [учебная запись запросов/ответов](wave-6-practice-examples.json).
Точное тело каждого входа, автор, HTTP-статус и ответ находятся в `trace` этого файла.
Секреты/Authorization-заголовки туда не входят. Без переменной файл отчёта не меняется.
Показ вручную через HTTP можно повторить по `trace`: подставлять ID из своего ответа,
использовать `Bearer fixture:<actor>`, запуск сервиса описан в README.
