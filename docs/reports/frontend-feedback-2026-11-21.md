# Исправления пользовательских сценариев, 21 ноября 2026

База: hr#100 (`20fd99b`). Функциональные исправления поверх отката #97–99,
без восстановления отменённых PR целиком. Четыре входа: соискатель, HR,
руководитель адресных передач, сотрудник.

- Портал читает публичный фасад Hiring. Опубликованные Requirements используются
  первыми; если каталог пуст, настроенный учебный контур использует существующие
  открытые Legacy-вакансии с утверждёнными профилями. Выбранная ссылка и редакция
  проверяются при подаче. Файл прикрепляется к настоящему обращению.
- Workforce-сессия общая для экранов и перечитывается после перезагрузки. Students
  на стенде проверяет тот же Bearer; подстановка fixture вместо сессии не используется.
- Единая база получает серверные candidate_id и application_id, фильтруется по
  вакансии. Три действия карточки — передача, архив, отказ. Перенос относится
  к конкретной передаче; остаток 10 рабочих дней берётся с сервера. Сводка
  отображает структурированный снимок. Интервью сохраняет контекст отклика.
- Архив открывает ArchivePage. Годовой доклад строит диаграммы по снимку;
  конструктор и XLSX используют одинаковые параметры. Форматы PDF/PPTX
  не обещаются, поскольку сервер их не выдаёт.

Проверки до публикации: TypeScript + Vite (74 модуля); кандидаты — реальный
FastAPI HTTP на SQLite, фильтр/два разных ID/401/403/разделение контуров;
годовой доклад — учебный operations-demo, три XLSX с MIME/ZIP/workbook.xml.
Это не полный набор и не доказательство всех рабочих кадровых процессов.

Открытые границы: ручной импорт в Legacy-базу HR требует серверной операции
(ложный успех убран); запись на мероприятия и внутренний переход сотрудника
не подключены к общей авторизации; опрос открывается по приглашению с кодом.
ФЗ-115 нельзя добавить без точного источника/названия; файл не найден в репозитории.
Синтетические резюме и вакансии массово не добавлялись.

Проверка после выпуска: публичный SHA/health; две разные вакансии и два кандидата;
архив и сводка; сохранённый отклик с файлом и повторный вход; диаграммы и скачивание XLSX.
