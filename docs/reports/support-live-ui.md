# Материальная помощь в интерфейсе

21 ноября 2026. База hr/main 5e7def8, ветка codex/support-live-ui. Компонент SupportPage подключается к настоящему сервису Social support. Существующие Card/Btn/Badge и оформление сохранены, изменения App и общего proxy выполняет интегрирующий агент.

Реализованы личный черновик, файл и подача, очередь координатора/назначение, кадровое подтверждение, проверка комплекта и запрос дополнения, ответ сотрудника с новой версией приложения, регистрация внешнего решения секретарём, личная выписка и отдельное состояние исполнения. Также есть формы назначения исполнителя, регистрации факта исполнения и закрытия дела.

Проверки — TypeScript/Vite build прошёл, один короткий реальный браузерный путь. Chrome 1440×1080, интерфейс http://127.0.0.1:19700/?workspace=support, proxy на сервис http://127.0.0.1:18106. SQLite и оригиналы в отдельном services/social-support/data-ui-check. Синтетические правила и акторы взяты из штатного сервиса.

Наблюдался путь черновик → application.txt → подача → назначение → confirmed кадровое основание → missing evidence → запрос дополнения → evidence.txt → дополнение → present по двум пунктам → ready_for_review → внешнее approved → личная выписка.
