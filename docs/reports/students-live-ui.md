# Практика студентов · подключённый интерфейс

21 ноября 2026. База 5e7def8, отдельная ветка codex/students-live-ui. Реализован самостоятельный StudentsWorkspace и клиент к существующему /api/v1/students. Общий App и прокси подключает интеграционная ветка. Оформление использует прежние Card/Btn/Badge, десктопную двухколоночную карточку, формы и список.

Операции интерфейса используют настоящий Students API с fixture-участниками. Можно создать и опубликовать место, подать заявку, назначить участие, опубликовать задание, сдать работу, вернуть её и подтвердить вторую попытку, завершить практику и отдельно внести вузовский результат. Студент выражает интерес, HR выбирает подтверждённые критерии и готовит карьерный пакет.

## Проверка

TypeScript/Vite прошли. Адресный компиляционный дефект Array.at исправлен под текущий ES2020. Отдельная SQLite frontend-practice.db создана миграцией Students, API запущен на 18505.

Один браузерный путь в Chrome 1440×1040 через общий Vite 19700 выполнил создание и публикацию места, заявку, назначение, задание, первую работу, доработку, вторую работу, подтверждение, полный итог наставника, отдельный зачёт вуза, интерес и prepared-пакет. Серверные записи учебные, без mock-ответов. При проверке обновления обнаружено, что повторный выбор текущей роли очищал видимые списки, не запуская повторное чтение. Добавлен guard, адресная проверка обновления выполняется отдельно после интеграции этой строки.

Инструкция с точными полями и ожидаемыми результатами — [frontend/STUDENTS.md](../../frontend/STUDENTS.md).

## Границы

Используется существующий standalone fixture-вход. Одно место и фиксированный учебный наставник department заданы формой первого сценария. Имена и данные студента приходят из заявки, а решения — из API. Состояние prepared-пакета подтверждается ответом сервера, автоматической передачи архиву нет. Диплом не подтверждается итогом практики. Общей операции чтения пакетов по участию API пока не предоставляет, поэтому после перезагрузки UI восстанавливает работы и итоги, а не список подготовленных пакетов.
