## Правила изменения контрактов

1. Общий контрольный пример для сквозной сверки всех контрактов — синтетический отклик **`py-9001`** на вакансию `python-dev` (базовый текст: `Написал API-тесты для сервиса заявок.`).
2. Добавление необязательного поля в JSON или нового значения в перечисление — совместимое изменение.
3. Удаление/переименование поля, изменение семантики ошибки или сигнатуры функции — несовместимое изменение: согласуется с Родионом и затронутыми владельцами на примере `py-9001` до слияния PR.
4. Описание внутреннего устройства каждого модуля его владелец поддерживает в `docs/modules/<модуль>.md`.
