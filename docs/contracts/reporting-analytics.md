# Управленческая аналитика кадров

## Что получает пользователь

Кадровая служба выпускает фиксированную версию доклада. Руководителю доступны сводка с основаниями, сравнение поступлений с прошлым годом, вклад вакансий в изменение, тепловая карта нагрузки и месяцы с необычным числом откликов. Для зарегистрированных разговоров можно оценить повторные контакты, исходы и скорость первого разговора. Датированные регистры подразделений добавляют штатные и занятые ставки, движение сотрудников и длительность ожидания ответов. [Формат кадровых реестров](reporting-operations.md)

## Доступ и интеграция

Базовый адрес — `/api/v1/reports/annual`. Старый интерфейс списка, снимка и Excel сохраняется. У всех запросов к рабочему отчёту одна проверка области доступа. Без учётных данных видны учебные снимки. Для рабочего подключения администратор явно задаёт `HR_REPORTS_WORK_SCOPE` и секрет `HR_REPORTS_WORK_TOKEN` на сервере. Сервис потребителя после собственной проверки прав сотрудника передаёт `Authorization: Bearer <token>` по защищённому соединению. Один ключ даёт чтение одной организации и служит для межсервисной интеграции. Клиентское приложение в браузере обращается к серверу своего приложения со своей сессией. Секрет хранится на серверной стороне. Если область или ключ не заданы, открыты только учебные отчёты.

| Операция относительно /{snapshot_id} | Что вернуть клиенту |
|---|---|
| GET /catalog | Список показателей с русскими названиями, единицами и определениями, разрешённые группировки, исходы, вакансии, подразделения, пять готовых запросов и признаки доступности источников. |
| GET /brief | Текст доклада, дата среза, охват и основание каждой фразы. |
| GET /signals | Вклад вакансий в годовое изменение, матрица месяц × вакансия, диагностика аномалий с базовыми месяцами, медианой, отклонением и причиной отсутствия сравнения. |
| POST /query | Фильтры, выбранные показатели, строки по группам и итоги за весь период. У чисел есть статус, причины, по применимости числитель, знаменатель и сопоставимая база. |
| POST /charts | Те же фильтры. Для каждого показателя готовая спецификация Vega-Lite с встроенными данными, подписями и подсказками. Можно также строить любой собственный график по /query. |
| POST /query/xlsx | Тело такое же, как для /query. Книга со сводкой среза, таблицей, диаграммами и параметрами запроса. |
| POST /operations | Срез по периоду и нескольким подразделениям. Запасы на конец интервала, потоки за период, ряды по месяцам и строки по подразделениям. |
| POST /operations/xlsx | Тот же срез по подразделениям в Excel. |
| GET /xlsx | Готовый годовой доклад в Excel с листом «К докладу», методикой, таблицами и диаграммами. |

Полный URL операции содержит префикс и ID, например `POST /api/v1/reports/annual/{snapshot_id}/query`. Запрос с неизвестной вакансией, метрикой или несовместимым разрезом получает 422. Рабочая версия вне разрешённой организации получает 404. Старый снимок без аналитического индекса сохраняет обычный просмотр и годовой экспорт. Для конструктора требуется повторный выпуск из исходного пакета, ответ 409 объясняет причину.

## Пример подключения без привязки к интерфейсу

```js
import { reportingClient } from "./integrations/reporting/client.mjs";

const api = reportingClient();
const versions = await api.versions(2025);
if (versions.length) {
  const id = versions[0].snapshot_id;
  const schema = await api.catalog(id);
  const recipe = {
    start_month: 1, end_month: 6,
    vacancy_keys: schema.vacancies.slice(0, 2).map(v => v.key),
    outcomes: ["continue", "stop"],
    metrics: ["phone_interviews_held", "applications_with_phone_interview"],
    group_by: ["quarter", "vacancy"], compare_previous: true
  };
  const data = await api.analyze(id, recipe);
  const { charts } = await api.charts(id, recipe);
  const workbookBlob = await api.downloadAnalysis(id, recipe);
}
```

[Клиент на Fetch API](../../integrations/reporting/client.mjs) работает в браузере и в Node с Fetch. Последним аргументом каждой операции можно передать AbortSignal при смене фильтра. Сохраните ID отчёта вместе с JSON запроса для воспроизведения среза. Экспорт принимает ровно этот JSON. Пример запроса по подразделениям — `{"start_month":1,"end_month":3,"departments":[]}`, пустой список включает все подразделения в разрешённой организации.

## Как читать числа

- Разговоры считаются по дате проведения, поступления — по дате отклика. Охват пересчитывается по всему запросу. Три месячных разговора по одному отклику дают один охваченный отклик за квартал.
- Доля продолжения рассчитывается по разговорам с известными решениями. Скорость первого контакта считается от даты поступления. Для показателя «за 14 дней» в знаменатель входят отклики, успевшие прожить все 14 дней. Медиана относится к откликам, по которым разговор состоялся к концу выбранного интервала. Процентные метрики имеют единицы процентов, абсолютная разница между двумя процентами измеряется в процентных пунктах.
- Изменение по каждой вакансии складывается в общее изменение. Выдача показывает и чистое изменение, и сумму абсолютных сдвигов, поэтому рост одной вакансии и падение другой видны даже при нулевом общем изменении.
- Для обнаружения необычного месяца нужна история минимум из шести полностью покрытых месяцев за предшествующие двенадцать. Основание — отклонение от медианы по MAD. Граница сигнала 3,5 нормированных отклонения. При постоянной базе изменение помечается отдельно. Это описательная проверка объёма, сезонная/причинная модель в ней отсутствует.
- У всех заявлений об объёме явно указана полнота. Аналитика не заменяет отсутствие первичного журнала нулём, а неопределённый процент оставляет пустым. Снимок содержит закрытый для HTTP индекс анонимных частот. Его контрольная сумма входит в идентификатор версии.
