# Контракт годового отчёта о подборе v1

[Конструктор аналитики, фильтры, управленческий доклад, доступ рабочего сервиса и интеграция фронтенда](reporting-analytics.md) · [Штат и передачи](reporting-operations.md)

Модуль получает пакет по одной организации или оговорённому списку вакансий. Время поступления отклика и время разговора относятся к разным событиям. Клиент может получить годовые показатели, ряды по месяцам, исходы разговоров, список вакансий и одну книгу Excel. [Полный учебный пакет](../../fixtures/reporting/demo/manifest.json) · [Команды запуска](../modules/reporting.md)

## Подготовка пакета

| Вход | Содержание |
|---|---|
| `manifest.json` | Версия `input_schema_version=1`, `csv_delimiter` (запятая или точка с запятой), `scope_id`, `scope_label`, `scope_revision`, `mode` (`work` или `demo`), зона IANA `timezone`, момент снятия выгрузки `extracted_at` с явным смещением, исключающая местная дата `observed_until`. Необязательный словарь `vacancies` задаёт допустимые ключи и подписи. В отсутствие словаря ключи служат подписями. |
| `sources.applications` и `sources.phone_interviews` в манифесте | Для каждого реестра обязательны `source_id`, `source_revision`, `comparable_to_previous_year` и список `complete_intervals`. Интервал — объект с местными датами `from` включительно и `to` исключительно. Поставщик заявляет полноту в оговорённом охвате и сопоставимость двух лет. |
| `applications.csv` | Строго три столбца `application_key,vacancy_key,applied_on`. Одна запись на отклик, ключи технические. Старые отклики включаются для связи с интервью. |
| `phone_interviews.csv` | Строго четыре столбца `interview_key,application_key,held_on,result`. Исходы `continue`, `stop`, `pending`, `no_answer`. Идентификатор отклика должен присутствовать в первом реестре. |

CSV читается в UTF-8 с допустимым BOM. Календарные даты имеют вид `2025-01-31`. Источник передаёт бизнес-даты в зоне отчёта. Например, для `Europe/Moscow` разговор в `2025-12-31T21:00:00Z` получает `held_on=2026-01-01`. Строка с повтором одного и того же ключа и значений учитывается однократно. Конфликт значений отклоняет пакет. Поставщик заранее исключает посторонние организации, учебные записи рабочего охвата и внешние записи истории, которые нельзя отнести к вакансии. В заголовках и справочнике разрешены только согласованные обезличенные описания.

## Даты и числа

Отчёт рассчитывается за период от первого января до меньшей из двух границ — следующего первого января и `observed_until`. Поле `interim` указывает на промежуточный период. Отдельно вычисляются календарные месяцы предыдущего года из той же выгрузки.

- `applications_received` считает разные отклики по `applied_on`.
- `phone_interviews_held` считает разные разговоры по `held_on`. Проведённый разговор с исходом `pending` учитывается. `no_answer` с указанной датой разговора отклоняется как противоречие. Исходы `continue` и `stop` без даты входят в счётчик недатированных разговоров.
- `applications_with_phone_interview` считает уникальные отклики с разговором за интервал. Несколько разговоров с одним откликом за год дают единицу, даже если прошли в разных месяцах.
- На уровне вакансии действуют те же три показателя. Интервью отнесено к вакансии связанного отклика. Сортировка по убыванию поступлений и затем по ключу. Общий источник интервью определяет покрытие для всех его исходов.

В каждой ячейке передаются `value`, `status`, `reason_codes`. При `complete` число точное, включая ноль. При `partial` положительное число служит нижней границей, при нуле наблюдений значение равно `null`. Для `unavailable` и `future` значение тоже `null`. Недатированные учитываемые факты снижают полноту своего реестра для обоих лет. Коды причин — `coverage_gap`, `coverage_unknown`, `missing_business_date`, `outside_period`.

Для двух закрытых, полных и сопоставимых лет вычисляются `delta` и `percent`. Относительная разница возвращается в процентах, округление до двух знаков. При нулевой базе есть абсолютная разница и причина `zero_baseline`. Для промежуточного года, несопоставимого источника или неполноты используются `interim_period`, `incomparable_source` и `incomplete_coverage`.

## HTTP

Точки входа основного приложения и автономного сервиса используют один роутер. Анонимная выдача ограничена учебными снимками. Рабочая выгрузка доступна локально через CLI и авторизованному серверу потребителя в пределах его организации. Схемы запросов и базового снимка доступны в OpenAPI.

| GET | Успех |
|---|---|
| `/api/v1/reports/annual` | Массив версий, включая пустой. Необязательный `year`. Новейшая дата выгрузки первая. |
| `/api/v1/reports/annual/{snapshot_id}` | Метаданные, `quality`, `totals`, `previous_totals`, `comparison`, `months`, `previous_months`, `vacancies`, происхождение и контрольная сумма пакета. Для каждого месяца в `outcomes` три исхода разговора, в `metrics` три показателя и в `vacancies` разрез по вакансиям. |
| `/api/v1/reports/annual/{snapshot_id}/xlsx` | Годовая книга из той же версии с итогами, помесячными данными, вакансийным разрезом, методикой и нативными диаграммами. MIME `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`. |

ID состоит из 64 строчных шестнадцатеричных символов. Неверный формат даёт 422, отсутствие версии и запрос рабочего снимка за пределами разрешённого охвата — 404. Нарушение целостности сохранённой версии — 500. Ошибка содержит `error.code`, `error.message`, `error.details`. Повторная выдача версии не обращается к исходным реестрам.
