# Практика студентов

Изолированный пакет services/students с SQL-хранилищем документов и аудитом. Реализуемые части: 3A место/заявка/участие, затем 3B задания и проверка, затем 3C итоги и карьерный пакет. Контракт: [wave-3-students-stage-1](../contracts/wave-3-students-stage-1.md).

Наставник имеет доступ по mentor_actor_id участия, студент — по student_actor_id. Общая роль department/employee не раскрывает все участия. Организатор работает в собственной организации. UUID не склеиваются по имени. Учебный режим явно отдаётся /health.

Команды изменения сериализованы на организацию (на SQLite — база целиком). Проверка вместимости и нагрузки выполняется в одной транзакции с назначением; повтор возвращает сохранённый результат. История — отдельные неизменяемые снимки каждого ресурса, ссылки и переходы контролирует доменный слой. При будущем выделении сервисов проверки ссылок должны быть сохранены; SQL FK для JSON-ссылок отсутствуют.

[Запуск и HTTP-пример](../../services/students/README.md), [проверка 3A](../reports/wave-3a-practice.md). Массовая производительность и PostgreSQL пока не проверены.

3B реализован в students/work.py: версии задания, попытки и отзывы хранятся отдельными ресурсами. Последнее применимое задание определяет критерии; отзыв не перезаписывает прошлый. work_state вычисляется из последней попытки. [Протокол 3B](../reports/wave-3b-practice.md).

3C реализован в students/results.py. Итог фиксирует снимок критериев последней применимой попытки, вузовский результат сохраняет отдельного внешнего автора/источник. Пакет включает только выбранные confirmed результаты; новый требует действующего интереса, прежний при отзыве получает историческую пометку. Доступ к пакету ограничен организатором и студентом, наставнику не предоставляется. [Протокол 3C](../reports/wave-3c-practice.md).
