# Годовой отчёт по подбору

Вход — пакет одной организации. На выходе — сохранённая версия годового отчёта в JSON и Excel. Снимок содержит числа и метаданные. Локальный оператор хранит исходный разрешённый пакет отдельно. [Контракт](../contracts/reporting.md)

## Запуск из корня продукта

Python 3.13 и uv. Для этого модуля доступ к PostgreSQL не требуется. Команды в PowerShell используют каталог версий по умолчанию `~/.hr-platform/annual-reports`. Можно задать `HR_REPORTS_DIR` до запуска CLI и сервера, указав локальную папку вне репозитория и веб-раздачи.

```powershell
uv sync --locked
uv run python -m app.reporting validate fixtures/reporting/demo
$report = uv run python -m app.reporting generate fixtures/reporting/demo --year 2025 | ConvertFrom-Json
uv run python -m app.reporting list --year 2025
uv run python -m app.reporting export $report.snapshot_id --output report-2025.xlsx
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Из второй консоли откройте список версий, получите JSON и скачайте книгу. Готовность сервиса можно проверить по ответу списка. Для расширенного доклада с двумя годами событий, четырьмя вакансиями, штатом и передачами используйте полный учебный сценарий ниже.

```powershell
uv run python -m scripts.make_reporting_showcase ./demo-leadership-input
uv run python -m app.reporting generate ./demo-leadership-input --year 2025
```

Список фильтров и готовых запросов, встраиваемые спецификации графиков, служебный доступ к одному рабочему охвату и выгрузка выбранного среза описаны в [контракте аналитики](../contracts/reporting-analytics.md). Клиент на Fetch API доступен в [integrations/reporting/client.mjs](../../integrations/reporting/client.mjs). Для использования реального архива добавьте к команде проверки кейса флаги `--save-snapshots --output <каталог>`.

```powershell
$base = 'http://127.0.0.1:8000/api/v1/reports/annual'
$versions = Invoke-RestMethod $base
$id = $versions[0].snapshot_id
Invoke-RestMethod "$base/$id"
Invoke-WebRequest "$base/$id/xlsx" -OutFile report-from-api.xlsx
```

Самостоятельный запуск — `uv run uvicorn app.reporting.api:app --host 127.0.0.1 --port 8000`. В обеих точках запуска анонимный HTTP даёт доступ к учебному каталогу. Рабочие снимки доступны через локальный CLI или служебному клиенту для назначенной организации. В манифесте рабочей выгрузки используется `mode=work`. Успех CLI даёт код 0 и JSON, ошибка возвращает ненулевой код и диагностику в stderr.

## Расчёт и версии

`loader.py` проверяет файлы, объединяет одинаковые записи и канонизирует пакет. `engine.py` определяет временные интервалы и агрегаты, применяет покрытие источника к ячейкам и формирует версию. `schema.py` описывает публичную схему. `store.py` публикует запись атомарно под SHA-256 от канонического JSON без поля ID. Одновременная генерация может опубликовать лишь один файл на ID. Изменение входа или методики даёт новую версию. `api.py` выдаёт сохранённые агрегаты. `excel.py` переносит их в книгу с числовыми ячейками, статусами и диаграммами. Проверка SHA при открытии выявляет порчу файла. Чтобы восстановить снимок, повторите расчёт из сохранённого пакета на соответствующей версии методики в отдельном каталоге и сверьте ID.

## Приёмка

```powershell
uv run pytest -q tests/test_reporting.py
uv run python -m scripts.check_reporting_case 'C:/путь/Кадры.zip'
```

Учебный отчёт за 2025 даёт 2 новых отклика, 4 разговора и 2 разных отклика с разговором. Три разговора относятся к январю. Проверка CLI поднимает обычный Uvicorn на временном локальном порту, скачивает книгу и сравнивает значения ячеек и перечень диаграмм. Для отдельной проверки реального архива скрипт использует подтверждённую папку консультанта из маппинга кейса. Читает дату основного отклика из DOCX, формирует временный обезличенный пакет и сверяет результат расчёта с прямым подсчётом дат. Печатает только агрегаты. Этот архив не содержит полного журнала телефонных интервью и подтверждения общегородского покрытия.
