# Срок ответа в карточке единой базы

`Кабинет HR-менеджера → Единая база → кандидат → Направить в департамент`.
При направлении сохраняются московская дата, получатель и срок через 10 рабочих
дней. День направления — день 0. Полоса заполняется до 100%, предупреждение
появляется за три рабочих дня до срока (день 7 исходного периода), красный статус —
на следующий календарный день после срока. В выходной после срока возможен
красный статус при счётчике 10 из 10: это соответствует серверному правилу.

Пример: направление 20.11.2026 → срок 04.12.2026. На 30.11 полоса 60%, зелёная;
01.12 — 70%, жёлтая; 07.12 — 100%, красная, прошло 11 рабочих дней. Продление до
11.12 даёт общий период 15 рабочих дней и возвращает статус на 07.12 в зелёный.
Дата обновляется каждые 30 секунд и при возврате во вкладку. Перезагрузка и
возврат из списка сохраняют исходную дату; у каждого ID кандидата свой срок.
Демонстрация просрочки не изменяет сохранённые данные и не позволяет продлить
вымышленный срок.

## Граница реализации

Эта карточка использует демонстрационные `c1…c8`. Срок хранится в localStorage
текущего браузера, отдельно по ID, и не отправляет уведомления. При архивировании
или отклонении локальный таймер удаляется. Это не замена серверным Handoff API
карточки отклика `CandidateCard`. Ошибка хранилища показана пользователю.

Календарные исключения в `handoffDeadline.ts` соответствуют существующему
`app/db/seed.py:PRODUCTION_CALENDAR_DAYS` (2025–2027); актуальность календаря за
другие годы и административные изменения БД этим экраном не покрываются.
При подключении единой базы к API нужно заменить локальные даты и календарь
серверными значениями; контракт backend в этой правке не меняется.

## Короткая проверка

В `frontend`, Node.js 22.6+:

```sh
node --experimental-strip-types --test tests/handoffDeadline.test.ts
npm run build
```

Для адресного браузерного сценария при необходимости: установить Playwright
локально (`npm install --no-save --package-lock=false @playwright/test`), установить
Chromium (`npx playwright install chromium`), открыть собранный frontend
(`npm run preview -- --host 127.0.0.1 --port 5189`) и выполнить
`node tests/handoff-progress.browser.mjs`. Нужны только локальный UI и
демонстрационные данные, без backend и внешних уведомлений. Скрипт проверяет
смену даты, цвета, ширину, продление, повторное открытие и изоляцию кандидатов.
